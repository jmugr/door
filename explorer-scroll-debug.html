Explorer Scrolling Diagnostic Tests

Test 1: Check CSS Computed Styles

In Browser Console:

  1. Open DevTools (F12)
  2. Run this to check .explorer-content overflow:
    3. const content = document.querySelector('.explorer-content'); console.log('explorer-content overflow:', window.getComputedStyle(content).overflow); console.log('explorer-content overflow-y:', window.getComputedStyle(content).overflowY);
  3. Run this to check .explorer-ul overflow:
    4. const ul = document.querySelector('.explorer-ul'); console.log('explorer-ul overflow:', window.getComputedStyle(ul).overflow); console.log('explorer-ul overflow-y:', window.getComputedStyle(ul).overflowY); console.log('explorer-ul has .overflow class:', ul.classList.contains('overflow'));

Expected Results:

  • .explorer-content overflow-y should be: hidden
  • .explorer-ul overflow-y should be: auto
  • .explorer-ul should have class: overflow

Test 2: Check Element Heights

In Browser Console:

const content = document.querySelector('.explorer-content'); const ul = document.querySelector('.explorer-ul'); console.log('explorer-content:', { clientHeight: content.clientHeight, scrollHeight: content.scrollHeight, offsetHeight: content.offsetHeight }); console.log('explorer-ul:', { clientHeight: ul.clientHeight, scrollHeight: ul.scrollHeight, offsetHeight: ul.offsetHeight });

Expected: ul.scrollHeight should be greater than ul.clientHeight if content is scrollable

Test 3: Check Pointer Events

In Browser Console:

const items = document.querySelectorAll('.explorer-ul li'); items.forEach((li, i) => { const style = window.getComputedStyle(li); if (i < 5) console.log(`li ${i} pointer-events:`, style.pointerEvents); });

Expected: Should be 'auto' or not 'none'

Test 4: Check Which Element Receives Scroll Events

In Browser Console:

const content = document.querySelector('.explorer-content'); const ul = document.querySelector('.explorer-ul'); content.addEventListener('wheel', (e) => { console.log('WHEEL on explorer-content', e.target.className); }); ul.addEventListener('wheel', (e) => { console.log('WHEEL on explorer-ul', e.target.className); }); console.log('Wheel listeners added. Now try scrolling over different elements.');

Instructions: After running this, try scrolling over:

  • A file link
  • A folder title
  • Empty space in the explorer
  • The scrollbar itself

Check console to see which element receives the event.

Test 5: Inspect DOM Structure

In Browser Console:

const ul = document.querySelector('.explorer-ul'); console.log('UL children count:', ul.children.length); console.log('Has overflow-end:', !!ul.querySelector('.overflow-end')); console.log('First 3 children:', Array.from(ul.children).slice(0, 3).map(c => c.className)); console.log('Last child:', ul.children[ul.children.length - 1]?.className);

Expected: Last child should be 'overflow-end'

Test 6: Check for Blocking Overlays

In Browser DevTools:

  1. Right-click on a file link in the Explorer
  2. Select "Inspect"
  3. In the Elements tab, look at the computed styles
  4. Check for any elements with high z-index that might be blocking
  5. Check if the li or a elements have any transform or position that creates a new stacking context

Test 7: Check CSS Specificity

In Browser Console:

const ul = document.querySelector('.explorer-ul'); const allRules = []; for (const sheet of document.styleSheets) { try { for (const rule of sheet.cssRules) { if (rule.selectorText && ul.matches(rule.selectorText)) { if (rule.style.overflow || rule.style.overflowY) { allRules.push({ selector: rule.selectorText, overflow: rule.style.overflow, overflowY: rule.style.overflowY }); } } } } catch (e) {} } console.table(allRules);

Test 8: Manual Scroll Test

In Browser Console:

const ul = document.querySelector('.explorer-ul'); ul.scrollTop = 100; setTimeout(() => console.log('Current scrollTop:', ul.scrollTop), 100);

Expected: scrollTop should be 100 (or less if not enough content)

Quick Fix to Test

Try this temporary CSS fix in Browser Console:

const style = document.createElement('style'); style.textContent = ` .explorer-ul li, .explorer-ul li > *, .folder-container, .folder-container > * { pointer-events: auto !important; } `; document.head.appendChild(style); console.log('Temporary fix applied. Try scrolling now.');

If this fixes it, the issue is with pointer-events CSS.
