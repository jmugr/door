Explorer Expand/Collapse Diagnostic Tests

Setup: First, collapse a few folders in the Explorer so you can test with both expanded and collapsed states.

Test 1: Check Collapsed Folder CSS

In Browser Console:

const folderOuters = document.querySelectorAll('.folder-outer'); console.log('Total folder-outer elements:', folderOuters.length); // Find a collapsed folder const collapsed = Array.from(folderOuters).find(f => !f.classList.contains('open')); if (collapsed) { const styles = window.getComputedStyle(collapsed); console.log('Collapsed folder-outer styles:'); console.log(' display:', styles.display); console.log(' grid-template-rows:', styles.gridTemplateRows); console.log(' visibility:', styles.visibility); console.log(' overflow:', styles.overflow); console.log(' height:', styles.height, 'computed'); console.log(' clientHeight:', collapsed.clientHeight); console.log(' scrollHeight:', collapsed.scrollHeight); const ul = collapsed.querySelector('ul'); if (ul) { console.log('Collapsed UL inside:'); console.log(' overflow:', window.getComputedStyle(ul).overflow); console.log(' clientHeight:', ul.clientHeight); console.log(' scrollHeight:', ul.scrollHeight); } } else { console.log('No collapsed folders found - collapse a folder first!'); }

Expected for collapsed:

  • grid-template-rows: 0fr
  • visibility: collapse
  • folder-outer clientHeight: 0 or very small

Test 3: Visual Height Check

In Browser Console:

// Add colored borders to see actual space taken const style = document.createElement('style'); style.id = 'debug-borders'; style.textContent = ` .folder-outer { border: 2px solid red !important; margin: 2px 0 !important; } .folder-outer.open { border-color: green !important; } .folder-outer > ul { border: 1px dashed blue !important; } `; document.head.appendChild(style); console.log('Debug borders added:'); console.log(' RED = collapsed folder-outer'); console.log(' GREEN = expanded folder-outer'); console.log(' BLUE dashed = UL inside'); console.log(''); console.log('Look at the Explorer. Do collapsed (RED) folders show any space?');

What to look for:

  • Collapsed folders (RED border) should have zero or minimal height
  • If RED borders show significant height, the collapse isn't working
  • BLUE dashed borders show the UL - should be hidden inside collapsed folders

To remove borders:

document.getElementById('debug-borders')?.remove();

Test 4: Check All CSS Rules Applied

In Browser Console:

const collapsed = document.querySelector('.folder-outer:not(.open)'); if (collapsed) { const allRules = []; for (const sheet of document.styleSheets) { try { for (const rule of sheet.cssRules) { if (rule.selectorText && collapsed.matches(rule.selectorText)) { const relevantProps = ['display', 'grid-template-rows', 'visibility', 'overflow', 'height']; const props = {}; relevantProps.forEach(prop => { const value = rule.style[prop] || rule.style[prop.replace(/-([a-z])/g, (m, c) => c.toUpperCase())]; if (value) props[prop] = value; }); if (Object.keys(props).length > 0) { allRules.push({ selector: rule.selectorText, ...props }); } } } } catch (e) {} } console.table(allRules); } else { console.log('Please collapse at least one folder first'); }

Look for: Multiple rules affecting grid-template-rows or visibility

Test 5: Toggle and Measure

In Browser Console:

// Find a folder to test with const folderOuter = document.querySelector('.folder-outer.open'); if (folderOuter) { console.log('BEFORE toggle (expanded):'); console.log(' classes:', folderOuter.className); console.log(' grid-template-rows:', window.getComputedStyle(folderOuter).gridTemplateRows); console.log(' clientHeight:', folderOuter.clientHeight); // Toggle folderOuter.classList.remove('open'); // Wait for animation setTimeout(() => { console.log('AFTER toggle (collapsed):'); console.log(' classes:', folderOuter.className); console.log(' grid-template-rows:', window.getComputedStyle(folderOuter).gridTemplateRows); console.log(' clientHeight:', folderOuter.clientHeight); // Toggle back folderOuter.classList.add('open'); console.log('Toggled back to open'); }, 350); } else { console.log('No open folders found'); }

Expected: clientHeight should go from a number to 0 (or very small)

Test 7: Live Animation Observer

In Browser Console:

// Watch folder collapses in real-time const observer = new MutationObserver((mutations) => { mutations.forEach((mutation) => { if (mutation.type === 'attributes' && mutation.attributeName === 'class') { const target = mutation.target; const isOpen = target.classList.contains('open'); const styles = window.getComputedStyle(target); console.log(`Folder ${isOpen ? 'OPENED' : 'CLOSED'}:`); console.log(' grid-template-rows:', styles.gridTemplateRows); console.log(' clientHeight:', target.clientHeight); console.log(' visibility:', styles.visibility); } }); }); document.querySelectorAll('.folder-outer').forEach(folder => { observer.observe(folder, { attributes: true }); }); console.log('Now watching folder toggles. Click folders to see real-time state.'); console.log('To stop: Run observer.disconnect()');
